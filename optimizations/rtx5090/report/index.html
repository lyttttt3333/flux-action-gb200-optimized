最后一轮，具体做了什么

打开卡片查看实现细节
AK 中心化 × INT8 quant+

在量化核中完成 K 减均值，并显式保留原来的 BF16 舍入。Q quant、scale 与 INT8 规则保持一致，消除 K 中间张量。

K → center + BF16 round + quant → INT8
主形状 K quant104.65 → 59.02 μs
BNorm / RoPE 直接写 NHD+

仅调整生成核最后的存储类型和位置，直接输出 BF16 / NHD。保留原算术及实际归约配置，省去 Q/K 独立转换与拷贝。

Norm / RoPE → BF16 · NHD → attention
作用范围5 early + 28 joint blocks
CV alias + tiled transpose+

直接引用 V+MLP projection 的 V 切片，省去 V 物化；以 64×64、4 warps 的 Triton tile 完成转置、padding 和 permutation。V mean / scale / quant 仍用原核，保留 V smooth。

V quant 整段，含搬运78.93 → 37.22 μs
D固定工作缓存+

缓存 timestep modulation、四步求解器 CPU 系数、同 seed 的噪声和位置 IDs。按依赖张量、seed、形状、设备及配置匹配；每个输入的观测推理仍照常执行。

输出检查逐位一致

组件时间来自对应真实形状测试，用于解释机会；不能直接相加或当作 E2E 加速倍数。

实验边界与保留的失败记录+

重启失败如实保留

早期 fresh runner 的 case 0 joint max 为 0.053043 rad；诊断 v1 为 0.071199 rad，均超过 0.05。最终冻结通过 gate 的具体配置后完成复现验证。这不是“所有 autotune 配置都能过 gate”的证明。

没有收益的方向停止集成

主要 GEMM 形状的同精度 autotune / padding 没有收益；改变 bits 且更慢的 FP8 attention-out 被拒绝。early BF16 小核理论收益上限约 0.23 ms / request，未继续移植。

已有优化不重复计算

CUDA Graph、共享 CFG、静态编译路径和融合 solver 已在前期基线中。最后一轮没有再将它们计算为新增收益，也没有减少推理步数。

5090 与 B200 分开看

本页只汇总完成验证的单卡 RTX 5090 路线。参考项目的 GB200 数据及本任务的 B200 VC-Attn 研究不并入这组结果；最终 5090 路径使用 SageAttention2。
